# Tracker from Eastern Kentucky Digital

This is a small tracking app I made to help me with my own productivity and hours billing. Feel free to use it as unlicensed software and on your own. The main application is to simplify synchronization with tailscale and to provide a GUI on MacOS and a cli on unix based systems in particular linux and MacOS. 

I hope it proves useful to any viewers and can help them. I intend to write most of the program in Rust, though I may rely on python if I also include a web end point as well.
